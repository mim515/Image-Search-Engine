## Overview

Image Search Engine is a dynamic web application that allows users to search for high-quality images using the Unsplash API. Built with HTML, CSS, and JavaScript, this project offers a seamless and visually engaging experience for discovering diverse and copyright-free images based on user-entered keywords.

## Features

Real-Time Image Search: Fetches and displays images instantly as users type their queries.

Responsive Design: Optimized for both desktop and mobile devices.

Infinite Scroll: Automatically loads more images as the user scrolls down.

Image Download: Allows users to download images directly from the interface.

Clean UI: Minimalistic and user-friendly interface for an enhanced user experience.

## Technologies Used

HTML5: For structuring the content.

CSS3: For styling and layout.

JavaScript (ES6): For dynamic content and interactivity.

Unsplash API: To fetch high-quality, royalty-free images.

## How to Use

Clone or download the repository.

Open index.html in your web browser.

Enter a keyword in the search bar to find relevant images.

Scroll to load more images or click on an image to download it.
